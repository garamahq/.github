# Security Policy

We take the security of our open-source tools, applications, and frameworks seriously. We appreciate your help in identifying vulnerabilities and disclosing them in a responsible, secure manner.

## Supported Versions

We support security updates for the latest major version of all active Satus repositories. 

| Project | Supported Version | Status |
| :--- | :--- | :--- |
| **bedrock-forge** | `>= 1.0.x` | :white_check_mark: Active |
| **cloudmesh** | `>= 1.0.x` | :white_check_mark: Active |
| **wp-secure-guard** | `>= 1.0.x` | :white_check_mark: Active |
| **gemeni-key-rotator** | `>= 1.0.x` | :white_check_mark: Active |
| All other utilities/templates | Latest release only | :warning: Best-effort |

## Reporting a Vulnerability

**Please do not open public issues for security vulnerabilities.**

If you discover a security issue, please report it through one of the following channels:

1.  **GitHub Private Vulnerability Reporting:** Go to the "Security" tab of the specific repository and click **Report a vulnerability** to submit a private draft advisory. This is the preferred method as it allows us to collaborate securely.
2.  **Email:** Contact the security team directly at [security@satus.dev](mailto:security@satus.dev).

### What to Include in a Report

To help us triage and resolve the issue quickly, please include:
*   A description of the vulnerability and its potential impact.
*   Steps to reproduce the vulnerability (including proof-of-concept scripts or payload examples where applicable).
*   Any details about the environment or configuration where the issue was observed.

### Our Response Process

*   **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
*   **Assessment:** We will investigate and verify the vulnerability. We may contact you for further details or clarification.
*   **Fix & Disclosure:** Once a fix is developed and tested, we will coordinate a release and publish a security advisory. We aim to resolve verified high-severity issues within 30 days of reporting.
*   **Attribution:** With your permission, we will gladly credit you for the discovery in our release notes and advisory.
