# Satus Organization Metadata (.github)

This repository (`.github`) is a special repository for the [Satus](https://github.com/satusdev) organization. It houses organization-wide community health files, templates, and the public profile README.

## 📁 Repository Structure

*   **`profile/`**: Contains the organization-wide landing page ([`profile/README.md`](profile/README.md)) displayed on the Satus organization homepage.
*   **`.github/`**: Houses issue and pull request templates shared across all repositories in the organization.
    *   [`ISSUE_TEMPLATE/bug_report.md`](.github/ISSUE_TEMPLATE/bug_report.md)
    *   [`ISSUE_TEMPLATE/feature_request.md`](.github/ISSUE_TEMPLATE/feature_request.md)
    *   [`pull_request_template.md`](.github/pull_request_template.md)
*   **`CODE_OF_CONDUCT.md`**: The community standard behavior agreement.
*   **`CONTRIBUTING.md`**: Guide for new and returning contributors outlining style guides and commit conventions.
*   **`SECURITY.md`**: Actionable instructions for privately reporting vulnerabilities and list of supported versions.

## 🤝 Community Standards

All repositories under the `satusdev` organization inherit the community files in this repository unless overridden by repository-specific files. If you are starting a new public repository for Satus, make sure you configure it to align with these standards.
