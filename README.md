# Garama HQ Organization Metadata (.github)

This repository (`.github`) is a special organization-level repository for [Garama HQ](https://github.com/garamahq). It houses organization-wide community health files, issue/PR templates, and the public profile README displayed on the Garama HQ GitHub landing page.

## 📁 Repository Structure

* **`profile/`**: Contains the organization profile landing page ([`profile/README.md`](profile/README.md)) displayed on the [Garama HQ GitHub organization homepage](https://github.com/garamahq).
  * **`profile/assets/`**: High-resolution banners, vector emblems, and visual assets used across profile documentation.
* **`.github/`**: Houses default issue and pull request templates inherited by repositories across the organization:
  * [`ISSUE_TEMPLATE/bug_report.md`](.github/ISSUE_TEMPLATE/bug_report.md)
  * [`ISSUE_TEMPLATE/feature_request.md`](.github/ISSUE_TEMPLATE/feature_request.md)
  * [`pull_request_template.md`](.github/pull_request_template.md)
* **`CODE_OF_CONDUCT.md`**: Community standard behavior agreement and reporting guidelines.
* **`CONTRIBUTING.md`**: Contributing guide outlining style standards, workflow, and Conventional Commits conventions.
* **`SECURITY.md`**: Security vulnerability reporting procedures, supported versions, and private disclosure policies.

## 🤝 Community Standards

All repositories under the `garamahq` organization inherit the community files in this repository unless overridden by repository-specific configurations. When creating new public or private repositories under Garama HQ, verify they adhere to these baseline standards.
