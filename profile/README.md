## 🏛️ About Garama

> **"Strategy beneath. Growth above."**  
> *استراتيجية في العمق، ونمو في الأفق.*

Named after the ancient kingdom of **Garama** (*Germa*) in southern Libya, our engineering philosophy draws inspiration from their historic *foggara* aquifer channels—intricate underground gravity aqueducts built deep beneath arid desert sands to channel life across vast territories and sustain thriving civilization above.

**Garama** operates as a digital product and software engineering studio based in **Misrata, Libya**. We build the quiet, mission-critical backbones that modern enterprises, multi-branch operations, and regional founders depend upon: from multi-tenant SaaS platforms and offline-first mobile applications to transactional data pipelines and hardened cloud infrastructure.

## 🤝 Contributing

We welcome contributions from developers and engineers worldwide! Whether fixing bugs, submitting feature requests, or improving documentation:

1. **Review Guidelines:** Check our [Contributing Guide](https://github.com/garamahq/.github/blob/main/CONTRIBUTING.md).
2. **Code of Conduct:** Review our [Code of Conduct](https://github.com/garamahq/.github/blob/main/CODE_OF_CONDUCT.md).
3. **Conventional Commits:** Keep commits atomic, well-described, and structured per Conventional Commits:
   ```bash
   feat(edge): configure zero-downtime TLS renewal in Caddy
   fix(auth): prevent race condition during session revalidation
   ```

## 🔒 Security

Security and data integrity are fundamental to our architecture. If you identify any vulnerability in our software or services:

* Please consult our [Security Policy](https://github.com/garamahq/.github/blob/main/SECURITY.md).
* Submit reports privately via GitHub Security Advisories or by emailing [security@garama.ly](mailto:security@garama.ly) / [hello@garama.ly](mailto:hello@garama.ly).
* **Never disclose security issues publicly.**
